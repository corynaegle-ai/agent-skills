# Skill documentation in this fork

Each promoted skill has `docs/<bucket>/<name>.md`. Update it whenever behavior changes. Keep four sections: What it does, When to reach for it, Common questions, and It's working if. Add prerequisites or neighboring-skill links only when useful.

Explain observable behavior and limitations without copying the runbook. Prefer questions demonstrated by project use or the upstream issue history; avoid padding. Link other skills through repository-relative paths so readers see the adapted version. Root installation wording lives in `.agents/install-block.md`; do not copy commands into every skill page. These pages describe this fork and are not published to upstream's aihero.dev site.
