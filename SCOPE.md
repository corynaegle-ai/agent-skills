# Scope

Reusable engineering workflows for autonomous coding agents across projects. This fork preserves Matt Pocock's MIT-licensed skill library and adapts selected workflows around concrete observed failures.

Changes should improve a repeatable workflow, preserve the target project's conventions and user authorization, and have observable validation where practical. Keep deterministic safeguards in scripts and contextual judgment in skills. Avoid adding process that does not change outcomes.

The supported default is the six skills in `skills.json`. The full promoted library is opt-in. Experimental and misc folders are inherited reference material, excluded from installation and plugin packaging. `.out-of-scope/` records historical upstream decisions, not this fork's contribution policy.
