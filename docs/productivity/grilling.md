## What it does

Resolve material open decisions through focused questions. Reuse settled decisions, look up facts, and make routine reversible implementation choices within existing authorization.

## When to reach for it

Use when the user requests an interview or significant unresolved choices affect the work. It can be explicitly selected or used when a relevant task fits.

## Common questions

**Will it ask unlimited questions?**

The default is a small round of one to three independent questions. Ask further only when answers could materially change the result; honor requested depth or limits.

**Does a planning session authorize building?**

No. Planning-only interviews stay planning-only. An already-authorized implementation continues once significant decisions are settled without a generic extra approval gate.

## It's working if

- Questions have a concise recommendation and consequence.
- The agent looks up facts instead of asking you to investigate.
- Settled choices are reused and authorized independent work continues.
